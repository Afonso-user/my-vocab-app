# 记忆工坊 · Study Edition

独立于 PONTE 的私人本地词卡工具，适合把自己的期中考试 Excel/CSV 学习资料变成快速背诵卡片。

## 使用方法

1. 在首页选择 CSV / TSV / TXT / XLSX / XLS。多工作表文件可选择工作表。
2. 自动识别词语、释义、音标、例句、语法、变位等字段；按需手动映射，预览首张卡。未映射列也会保存。
3. 自定义每轮新词数量、目标记忆率与考试日期，立即开始学习。

## 三种模式

- 今日学习：到期词优先（每轮最多 60 张），再接入指定数量的待排程词卡。
- 新词排程：评分「重来、困难、记得、简单」，建立 FSRS 记忆计划。
- 考前速刷：随机最多 100 张；只做强化阅读，不改变 FSRS 日程。

考试日期用于展示倒计时和建议每日首次排程数量，并非对学习效果的保证。
键盘：空格或 Enter 翻面、1–4 评价、Enter / 右箭头进入下一张。进入下一张前可以撤销评分。

## 本地数据

全部数据只保存在**当前浏览器 localStorage**，不需要账户也不上传词书。换设备、清理浏览器数据或进入隐私模式可能导致记录不在，请先在首页**导出 JSON 备份**，另一台设备再手动恢复。

以前的学习次数会保留，但不会被伪装成 FSRS 历史；旧词卡要在新版首次评分后才有有效的 FSRS 日程。
解析最大 10,000 行；浏览器空间可能更小，较大词库请拆分。语音合成语言包取决于设备。

## 本地开发

需要 Node.js 22+：

```bash
npm ci
npm run dev
npm run build
npm run lint
npm test
```

GitHub Pages 只发布默认分支；当前开发分支与草稿 PR 不会自动更新线上。
